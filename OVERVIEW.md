# Power BI Portfolio

My collection of Power BI dashboard projects. Each project lives in its own folder with its screenshots, documents, and data notes inside.

## Roadmap

| # | Project | Dataset | Skills practiced |
|---|---------|---------|------------------|
| 1 | Delivery & Logistics (Olist orders) | Olist Brazilian E-Commerce | Cleaning, DAX basics, KPIs, trends |
| 2 | Sales Dashboard | Superstore Sales / Global Superstore | Revenue, profit, categories, regions, year-over-year |
| 3 | Olist Data Modeling | Olist Brazilian E-Commerce: customers, order items, sellers | Data modeling, relationships, maps (late % by state) |
| 4 | HR / Employee Analytics | HR Attrition / IBM HR Analytics | Slicers, percentages, demographic breakdowns |
| 5 | Finance / Budget Tracker | Budget or expense dataset | Budget vs. actual, variance, time intelligence |
| 6 | Live-refresh Project | Small Excel file I maintain myself | OneDrive source, publishing, scheduled refresh |
